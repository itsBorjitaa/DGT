# DGT
Proyecto de la DGT para la asignatura de Programación IV de la Universidad de Deusto.

En el módulo main.c está comentado en la línea 7 el comando para compilar el proyecto. Una vez ejecutado el comando en la terminal se crea: "main.exe". En la línea 8 sale cómo ejecutarlo por terminal.

Una vez ejecutado accedemos al menu principal, en el que podremos registrarnos o iniciar sesión, hay unos datos ya insertados en la base de datos que se pueden leer comentados en el main.c . De igual manera puedes crear un nuevo usuario si lo deseas. A partir de ahí no hay pérdida podrás ejecutar las diferentes opciones que salgan enumeradas para cada menu. Estás variarán en función de si eres un usuario o un administrador.
